# 点菜篇

在外省点菜，和在自己家楼下点菜是两回事．外省的"微辣"不是广东的微辣，外省的"青菜"也不一定是广东的青菜．这一篇讲的是：在一张不太熟的菜单上，怎么点出一桌自己吃得舒服、同学也不尴尬的菜．

## 一、关于辣

### 1.1 注意事项

1. **外省口味默认值不一样．** 在很多外省城市，店里的"微辣"对广东人来说已经很辣；说"少辣"，端上来的可能还是一层红油．
2. **在广东见得少的菜可能会被“误导”**．如 “水煮肉片” 其实是川菜，不是像那种冬瓜肉片汤那样把肉片下到清水里煮．

### 1.2 如果你吃不了辣，又不想吃到很辣的东西

直接和服务员或老板说：

1. 直接避免去湘菜馆或川菜馆．
2. 和老板说 "**我们是广东来的，吃不了太辣，麻烦一点辣椒都不要放．**"
   直接说比含蓄说管用，很多店家听到"广东来的"，自己会收敛．
3. 和老板说 "**一点辣椒都不要放**"，而不是"少辣"．
   不放心的话，再加一句"辣椒单独给我一碟"．
4. 和老板说 "**这个菜能不能做得清一点？少油少盐．**"
   炒菜、汤、蒸菜一般可以商量；干锅、水煮这类基本不行．
5. 点菜的时候，关注：清蒸、白灼、清炒、炖汤、蒸蛋、粥．

### 1.3 菜单中很辣的东西：

| 菜单上写 | 大概是什么意思 |
| --- | --- |
| 麻辣、香辣、酸辣、剁椒、泡椒 | 重辣，慎点 |
| 水煮、干锅、口味（比如"口味虾"） | 重辣重油 |
| 小米辣、朝天椒、爆辣、变态辣 | 字面意思 |
| 微辣 | 在外省，常常等于广东的中辣往上 |

做法相关的字眼：

| 看到这些 | 说明 |
| --- | --- |
| 清蒸、白灼、清炒、蒜蓉、上汤、炖、蒸蛋、汤面 | 相对接近广东口味，可以优先点 |
| 红烧、爆炒、干煸、香酥、油炸、扣肉 | 油重，广东胃容易顶不住 |
| 卤味、酱烧、酸菜、腌菜 | 偏咸，点之前有心理准备 |

### 1.4 一些大概率不会踩雷的菜

建议去新店探店的时候点一些保底的菜，这里列举一部分：

- 鸡蛋：蒸水蛋、滑蛋、涨蛋、蛋饼、番茄炒蛋、韭菜炒蛋（或淮扬小炒）
- 素菜：清炒时蔬、蒜蓉时蔬
- 汤类：冬瓜（玉米）排骨汤、番茄蛋汤、紫菜蛋花汤，以及其它炖汤
- 糖醋里脊
- 鱼类：清蒸鱼、一鱼多吃（炒鱼片和鱼汤）【**注：** 确保鱼是新鲜的，也确保该菜受欢迎】

总之探店的时候，避免点过多的重口味的菜（如：臭豆腐）或味型复合（如：鱼香茄子）

## 二、关于素菜

在广东，经常用“青菜”二字来代指绿叶菜，但外省对素菜、青菜的概念可能和广东不一样．

1. 外省的“素菜”可能还包括辣炒土豆丝、地三鲜（土豆、茄子、青椒）

2. 外省的“青菜”可能指上海青（小白菜）．

   想吃到接近家乡的那种青菜，先向老板问清楚："**今天有什么绿叶菜？**"

3. 大概率不会踩雷的素菜：清炒时蔬、蒜蓉时蔬、上汤时蔬（店里有的话）．

另外，番茄炒蛋、蒸水蛋这类带蛋的菜不算素菜，但对广东胃很友好，可以当作保底菜；完整的保底菜清单见 1.4．

## 三、关于鱼类

### 3.1 表达习惯

1. 广东的“生鱼”学名“**乌鳢**”，在外省可能叫“黑鱼”或者“蛇头鱼”．
2. 广东的“鲩鱼”，在外省可能叫“草鱼”

### 3.2 吃鱼的注意事项

1. 鱼片要卷起来才新鲜
2. 清蒸鱼尽量点整条的，不要点切块的：切块容易藏不新鲜的部分，火候也不好控制．
3. 判断新鲜度：鱼眼清亮微凸、鱼鳃鲜红、按下去有弹性；很多店可以自己去鱼缸挑，挑活的．
4. 淡水鱼（黑鱼、草鱼）土腥味重，适合做鱼片汤、酸菜鱼这类口味重的做法；想吃清淡的，优先选桂花鱼（鳜鱼）、鲈鱼这类土腥味轻的．
5. 想点"一鱼多吃"（炒鱼片加鱼汤），最好确认是现杀整条，而且这道菜点的人多．

## 四、问老板：四个最好用的问题

### 4.1 问拿手菜

> "老板，你们最拿手的是哪道？"

问之前先说明自己吃不了太辣．老板推荐的有可能是真招牌，也有可能是利润最高或者库存最多的，所以推荐完再补一句："那你自己平时吃哪个？"

### 4.2 问老板自己最爱吃哪道

> "你自己最喜欢吃哪道？"

这是最值得问的一句．老板做给自己吃的菜，往往舍得下料、舍得花时间．老店的老板被问到这句，经常会顺口多说两句：今天什么新鲜、什么值得点．如果他报的菜是辣的，就顺便追问一句"有不辣的吗"．

### 4.3 问现在的蔬菜

> "今天有什么绿叶菜？清炒一个．"

菜市场每天的货都不一样，问"今天有什么"，问的其实是"你今天买到了什么好的"．外省不一定有菜心、芥兰、通菜，但一般的绿叶菜都有，举些例子：

- **菠菜**：秋冬到春天．
- **茼蒿**：秋冬到春天．
- **秋葵**：夏天到秋天（6月 - 9月）
- **香椿**：春天（3月 - 4月）
- **空心菜（通心菜、通菜）**：夏天到秋天（5月 - 10 月）

适合广东人的做法有清炒或者蒜蓉．

### 4.4 问汤

> "今天有什么汤？"

1. 外省没有老火汤，菜单上的汤大概是这几类：番茄蛋汤、紫菜蛋花汤、冬瓜排骨汤．
2. 外省可能还有胡辣汤、酸辣汤、火锅汤底等，这些不适合广东胃，不适应就慎点．

## 五、点多少、怎么搭

### 5.1 点菜指南

- **关键：** 荤素搭配，主食搭配，有汤就更好．
- **分量：** 外省菜分量普遍比广东大，尤其北方．两个人先点两道菜就够，人多了按"人数 ± 1"，不够再加．
- **预算**：参考美食点评软件，软件显示人均多少元，点菜时就上下浮动 20 % ．
- **避免重复：** 同一桌别点两条鱼、两只鸡、两盘牛肉等等，除非像鱼可能有“一鱼二吃”的做法，或者去吃大盘菜．
- **不点食堂也有的菜**：在外面吃饭，就不要点食堂也有的菜了，比如在南京上大学，在外面吃饭就没必要点米线、鸭血粉丝汤等．
- **横向对比**：如果你想横向对比两家不同的饭店，可以都点两家店的拿手菜，或者都点两家店的相同的一两道常见菜，这样就能分出高下．比如，在南京的粤菜餐厅，我喜欢点“干炒牛河”和“肠粉”来进行横向的对比．
- **吃不完打包**：中午吃不完打包留着晚上吃，晚上吃不完打包留着明天当早餐（前提是宿舍提供微波炉）．打包的时候注意不要打包一些不耐放的菜．

### 5.2 和其他人约饭

- **不熟的人一起吃饭**：此时要**慎点需要上手的菜**：小龙虾、螃蟹、棒骨．剥壳的时候没人说话，场子容易冷．
- **和外省同学约饭：** 别人点辣的，你就加一道不辣的，先保证桌上有自己能吃．
- **和导师约饭**：你就默默的吃就行了．



## 六、点评软件怎么看：分清真实评价和"打卡评价"

去之前查一下点评软件，已经是大学生的基本功．但要会看．

### 6.1 在外省找"接近广东口味"的店

1. 搜"粤菜""潮汕""猪脚饭""肠粉""烧腊"这类关键词，看看有没有老乡开的店．
2. 用你的家乡话和老板讲两句，如果老板会粤语，那大概率就是正宗的了．
3. 评价里重点看有没有"广东人开的""老板是潮州人""味道和家里一样"这类说法．反过来，如果差评都在说"改良过、不正宗、太咸太辣"，说明这家店已经彻底本地化，口味不一定合你．
4. 也不必执着于"正宗"．外省的粤菜馆大多做了本地化，能吃到熟悉的味道、价格合适，就值得再去．

### 6.2 怎么找有用的评价

1. 排序换成"最新"．默认推荐里混着商家的运营．
2. 重点看三到四星的中评．五星可能是刷的，一星可能是情绪，中评通常把话讲全．
3. 差评要看细节．写"上菜慢、菜是凉的、分量比图片少"的，可信；写"再也不来了"却没说前因后果的，参考价值不大．
4. 看图片的质感．随手拍、光线差、角度歪、背景里有别桌的胳膊，多半是真实顾客；九宫格精修、统一滤镜、摆拍角度，多半是探店合作．

### 6.3 怎么认出"打卡送东西"的评价

1. **先知道它长什么样．** 线下餐厅最常见的玩法是：在指定平台签到、打卡、写好评，就送一份小菜、甜品或者饮料；外卖则常出现"全五星好评加晒图，可领红包"的小卡片．这类"好评返现"已经被认定为不正当竞争手段，市场监管总局的规定明确禁止用返现、红包、卡券来换取指定好评．
2. **评价里出现"打卡送""收藏送菜""好评返现"，或者商家回复里有类似暗示，这一条就不用看了．**
3. 话很短、全在夸、没有细节、句式雷同（"绝了""YYDS""宝藏小店"），还集中在几天里一条接一条，这是任务评价的典型样子．
4. 点进对方主页：只评过这一家，或者几天内评了十几家店，基本可以确定是任务号．
5. 没有图、没有细节的五星好评，不能当参考．

### 6.4 高分不等于好吃

1. **有媒体调查过这条灰色产业链：**一家店每月花几千元，就能买到"挤进商圈前五、星级维持在 4.5 左右"的服务；一条"优质好评"标价几十元，账号等级越高越贵．
2. 有些评价甚至不用真的到店也能发出来，所以"评价数量多、账号等级高"本身说明不了什么．
3. **新店尤其要小心：**开张才两三个月，菜品和服务都还毛糙，却已经有一大堆模板化的好评，甚至顶着"某某区第一"的名头，这种情况明显不正常．
4. 如果一家店评价在 3.5 - 4.1 分（满分 5 分，最低分 1 分），可以重点看看，说不定能挖到隐藏宝藏．



## 七、外卖、烧烤和早餐

### 7.1 外卖

备注栏一定要写：不要辣、不要香菜、不要葱、少油少盐．备注比口头交代可靠，出了问题也有据可查．食堂窗口也一样，直接说"不要辣"三个字就行．

外卖评分和堂食是两回事，别用外卖评分判断这家店的堂食水平．

### 7.2 烧烤

烧烤默认撒辣椒面．点单时先说"不要辣"，上桌之前再确认一遍，因为不少摊子是烤好统一撒料的．另外烧烤上菜慢，点太多容易凉，先点一轮再加更稳．

### 7.3 早餐

外省的早餐和广东早茶是两套系统：想喝粥要确认是白粥还是小米粥，想吃粉要确认这家有没有；很多地方早餐只有包子、馒头、面条和豆浆．

## 附录：和老板沟通的模板

- 我们是广东来的，吃不了太辣，一点辣椒都不要放．
- 这个菜可以做清一点吗？少油少盐．
- 有没有不辣的菜？
- 老板有什么拿手菜？老板你喜欢哪一道菜？
- 今天有什么绿叶菜？
- 米饭要两碗，谢谢．
- 先上这些，不够再点．
